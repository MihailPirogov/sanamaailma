## What the app does (same shell as the other PirogovLab word games)
- Java WebView shell; game bundled offline in `assets/www`, served from `https://appassets.androidplatform.net/`; works offline, only ads need network.
- `AndroidBridge`: vibrate, share text, share word-card PNG (ContentProvider `ru.pirogovlab.sanamaailma.share`), openUrl, ads. Back button → `window.__appBack()` (tutorial/modal → home → exit). Audio muted on pause/ads.
- **Yandex Mobile Ads SDK 8.6.0** (`com.yandex.android:mobileads`): sticky banner after the tutorial; interstitial every 3rd win, ≥150 s apart; rewarded on tap only (hint letter, ×2 coins, extra wheel spin ≤3/day). Logcat tag `SanamaailmaAds`.
