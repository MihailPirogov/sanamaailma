Переводы **не придумываются**: если у слова нет русского перевода в ru.wiktionary, оно может быть только бонусным (без перевода).
English / Finnish Wiktionary не использовались: в en.wiktionary нет русских переводов финских слов (только английские толкования), объём ru.wiktionary хватает (≈7 500 нарицательных слов 3–8 букв).
Цитаты из Библии (примеры с источником Biblia 1776 и т.п.) из карточек удалены полностью.

Музыка: нет. Звуки — синтез WebAudio (js/sound.js). Фоны — процедурный SVG (js/art.js, свой код), иконка — img/icon.svg (своя).

## Частотник и отбор слов (с 19.10.2026)
Сводная частота леммы: Zipf = 0,65 · FrequencyWords (субтитры, разговорная речь) + 0,35 · wordfreq (общий язык); если лемма есть только в одном списке — его значение минус 0,3.
Порядок слов для кроссворда = сводная частота + 0,6 · (частота первого русского перевода − 4,2): так «talo — дом», «koira — собака» стоят выше, чем слова с редким или непервичным первым переводом.
Рассматривались и отклонены: списки Kielipankki / Института языков Финляндии (лицензии с ограничениями NC/ND или без явной открытой лицензии).
Слова, убранные из кроссворда (остаются только бонусными): редкие (сводный Zipf < 2,2), формы слов, а не словарные формы, специальные/устаревшие/диалектные пометы, заимствования-транслитерации, странный или непервичный первый перевод (в т.ч. редкий русский перевод), ссылки «см.», ручной список (`BONUS_ONLY` в `tools/lexicon.py`, например lama «спад», taso «плоскость», laki «потолок»). Местоимения и служебные слова — не раньше 250-го уровня.
